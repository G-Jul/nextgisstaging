# Инструкция по развертыванию документации NextGIS

## Требования

- Python 3.7+
- Sphinx

## Установка зависимостей

```bash
cd docs
pip install -r requirements.txt
```

## Локальная сборка

```bash
cd docs
python -m sphinx -b html source build
```

Результат будет в папке `build/`

## Развертывание на ReadTheDocs

1. Создайте аккаунт на [ReadTheDocs.org](https://readthedocs.org)
2. Подключите ваш репозиторий
3. ReadTheDocs автоматически соберет документацию из папки `docs/`
4. Убедитесь, что в настройках проекта указан правильный путь к `conf.py` (обычно `docs/source/conf.py`)

## Структура проекта

```
docs/
├── source/              # Исходники документации
│   ├── index.rst        # Главная страница и меню
│   ├── *.rst            # Страницы документации
│   ├── _static/         # CSS, JS, изображения
│   │   ├── custom.css   # Стили для внутренних страниц
│   │   ├── homepage.css # Стили для главной страницы
│   │   ├── custom.js    # JS для внутренних страниц
│   │   └── homepage.js  # JS для главной страницы
│   └── conf.py          # Конфигурация Sphinx
├── build/               # Собранная документация (генерируется)
└── requirements.txt     # Зависимости Python
```

## Проверка работы

После развертывания проверьте:

- Главная страница отображается корректно
- Внутренние страницы работают
- Навигация (левое и правое меню) функционирует
- Адаптивность на разных устройствах
- Бургер-меню работает на мобильных устройствах
