# Как добавить новую страницу в документацию

## Быстрый старт

1. Создайте новый файл `.rst` в папке `docs/source/`
   - Например: `my-page.rst`

2. Добавьте содержимое страницы в формате reStructuredText:

```rst
Моя новая страница
==================

Это заголовок первого уровня.

Подзаголовок
------------

Это заголовок второго уровня.

Текст страницы с **жирным** и *курсивным* текстом.

Список:
- Пункт 1
- Пункт 2
- Пункт 3
```

3. Добавьте страницу в меню, отредактировав файл `docs/source/index.rst`:

```rst
.. toctree::
   :maxdepth: 2

   my-page
   другие-страницы
```

4. Пересоберите документацию:

```bash
cd docs
python -m sphinx -b html source build
```

5. Откройте `docs/build/index.html` в браузере для просмотра.

## Важные моменты

- Файлы должны быть в формате `.rst` (reStructuredText)
- Название файла без расширения добавляется в `index.rst`
- После изменений всегда пересобирайте документацию
- Готовые HTML файлы находятся в папке `docs/build/`

## Пример структуры

```
docs/
├── source/
│   ├── index.rst          # Главное меню
│   ├── my-page.rst        # Ваша страница
│   └── _static/           # CSS и JS файлы
└── build/                 # Собранные HTML файлы
```
