Разница отрисовки стилей в QGIS и NextGIS Web
-----------------------------------------------

Поскольку в NextGIS Web отрисовку слоёв выполняют оригинальные библиотеки QGIS, большинство вариантов стилизации и рендеринга работают хорошо. Однако есть большая разница между QGIS и NextGIS Web в том, как они компонуют слои. QGIS отрисовывает слои вместе и помещает подписи поверх всех слоев. NextGIS Web отрисовывает слои по одному (или даже тайл за тайлом) и собирает их вместе на стороне веб-клиента. Поэтому рендеринг стилей QGIS в NextGIS Web может отличаться следующим образом:

* Не поддерживаются режимы смешивания.
* Подписи разных слоёв могут накладываться.
* Не работают SVG-маркеры, заданные выражениями.
* Не работает маскирование, поскольку это механизм проекта, а не слоя.

Посмотреть версию QGIS, которая в настоящий момент используется для рендеринга, можно в `Панели управления <https://docs.nextgis.ru/docs_ngweb/source/admin_interface.html#ngw-control-panel>`_ в разделе `Информация о системе <https://docs.nextgis.ru/docs_ngweb/source/infowebgis.html#ngw-system-info>`_.

Как получить помощь или сообщить об ошибке
-------------------------------------------

Если вы не нашли ответ на свой вопрос в этом руководстве, попробуйте обратиться к `полной документации <http://docs.nextgis.ru/docs_ngweb/source/index.html>`_  по NextGIS Web.

Сообщить об ошибках можно по почте info@nextgis.ru. 

Прямая поддержка и дополнительные услуги доступны в рамках плана Premium (`подробнее <https://nextgis.ru/pricing-base/>`_).

Неофициальная поддержка и обсуждения, касающиеся работы сервиса, доступны в публичной группе Telegram `NextGIS <https://t.me/nextgis_chat>`_.
