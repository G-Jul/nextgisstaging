.. _ngcollector_auth:

Авторизация
===========

Через облачный сервер (my.nextgis.com)
--------------------------------------

Авторизация в приложении NextGIS Collector осуществляется через сервер https://my.nextgis.com/.
В качестве логина и пароля используется почта и пароль от личного кабинета пользователя NextGIS ID.

.. figure:: _static/ngc_login_ru_2.jpg
   :name: ngc-user-05
   :align: center
   :width: 10cm

   Экран авторизации


Через собственный сервер (NGIDOP)
---------------------------------

Для авторизации в NextGIS Collector через локальный сервер необходимо сменить сервер авторизации при входе в приложение (см. :numref:`ngidop_collector`). Если вы перед этим уже вошли через my.nextgis.com - необходимо сначала выйти.

.. figure:: _static/ngc_ngidop_ru.png
   :name: ngidop_collector
   :align: center
   :width: 10cm
   
   Добавление собственного сервера авторизации в NextGIS Collector


Управление пользователями происходит через раздел `"Команда" <https://docs.nextgis.ru/docs_ngid/source/ngidop.html#ngidop-teams>`_ в настройках NextGIS ID on-premise.
Администратор предварительно создаёт в нем пользователей, которые будут осуществлять сбор данных.


.. _ngcollector_auth_change:

Сменить пользователя
------------------------

Посмотреть, под какой учётной записью вы авторизованы в данный момент, можно в меню "Настройки". Внизу страницы вы увидите адрес электронной почты, а также ID устройства.

.. figure:: _static/ngc_ngid_view_ru.png
   :name: ngc_ngid_view_pic
   :align: center
   :width: 10cm

   Сведения об авторизованном пользователе в настройках NextGIS Collector

Чтобы войти под другой учётной записью, нажмите "Выйти из аккаунта" и затем авторизуйтесь, как описано выше.
